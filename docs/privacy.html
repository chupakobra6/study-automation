Политика конфиденциальности

Gmail подключается с разрешением gmail.readonly. Оно позволяет читать почту; приложение использует настроенные поисковые запросы для выбора учебных сообщений. Через это подключение приложение не отправляет письма, не удаляет их и не меняет состояние ящика.

Выбранные письма, их заголовки, текст и доступные вложения сохраняются локально на компьютере владельца. Токен доступа для повторной авторизации хранится в macOS Keychain. Эти данные нужны для определения учебных требований, действий и сроков.

При разборе сводки необходимые материалы могут передаваться в OpenAI через Codex в учётной записи владельца. Их обработка также регулируется действующими условиями и настройками используемого сервиса. Данные Gmail не публикуются на этом сайте и не продаются.

Использование данных Google ограничено указанными учебными целями и соответствует Google API Services User Data Policy, включая Limited Use. Приложение не использует данные Gmail для рекламы или обучения общих моделей. Доступ можно отозвать в настройках Google Account; локально сохранённые материалы удаляются отдельно владельцем.

Вопросы о приложении и данных: issues публичного репозитория (не публикуйте письма, токены или персональные данные).
