Study Monitoring

Личный инструмент для наблюдения за учебными заданиями, сроками и сообщениями. Он запускается на компьютере владельца и формирует учебную сводку из настроенных источников.

Gmail подключается с разрешением gmail.readonly для чтения выбранной учебной почты. Приложение не отправляет письма через это подключение.

Публичный репозиторий содержит общий код и тесты. Персональные настройки, письма, учебные материалы и токены не публикуются.

Перед подключением ознакомьтесь с политикой конфиденциальности и условиями использования.
